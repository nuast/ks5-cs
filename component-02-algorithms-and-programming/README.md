### OCR pseudocode reminder

OCR uses its own pseudocode style in exams. Key points:

```
// Comments use double slash
x ← 5              // assignment uses left arrow
IF condition THEN
    ...
ELSE
    ...
ENDIF

FOR i ← 1 TO 10
    ...
ENDFOR

WHILE condition DO
    ...
ENDWHILE

FUNCTION name(param)
    RETURN value
ENDFUNCTION

PROCEDURE name(param)
    ...
ENDPROCEDURE
```

You will be expected to **read, trace, and write** pseudocode in this style.
