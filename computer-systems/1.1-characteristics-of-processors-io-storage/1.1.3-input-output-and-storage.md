# 1.1.3 Input, Output and Storage

> **Component:** 01 — Computer Systems | **Section:** 1.1 | **Sub-section:** 1.1.3

---

## What you need to know

Computers need to receive data (input), produce results (output), and store information persistently (storage). This topic covers the different categories of input and output devices, the types of storage available, and how they compare in terms of **speed, capacity, cost, and persistence**. Expect comparison and justification questions.

## Key terms

| Term | Definition |
|------|-----------|
| **RAM** | Random Access Memory — fast, volatile (loses data when powered off); used for current programs and data |
| **ROM** | Read-Only Memory — non-volatile; stores permanent firmware (e.g. BIOS/UEFI) |
| **Cache** | Very fast, small memory between CPU and RAM; stores frequently used data |
| **Virtual memory** | Using part of secondary storage (HDD/SSD) as if it were RAM when RAM is full |
| **Magnetic storage** | Uses magnetic fields on a spinning disk (HDD); high capacity, relatively slow |
| **Optical storage** | Uses laser and pits/lands on a disc (CD/DVD/Blu-ray); portable, slower |
| **Solid-state storage** | Uses flash memory with no moving parts (SSD, USB flash drive); fast, durable |
| **Cloud storage** | Data stored on remote servers accessed over the internet |
| **Volatile** | Loses data when powered off (e.g. RAM) |
| **Non-volatile** | Retains data without power (e.g. ROM, HDD, SSD) |

### Storage types compared

| Property | Magnetic HDD | Optical (DVD) | Solid-state (SSD) |
|----------|-------------|---------------|------------------|
| **Speed** | Moderate | Slow | Fast |
| **Capacity** | Very high (TBs) | Low (up to 100 GB) | High (GBs–TBs) |
| **Cost per GB** | Low | Very low | Higher |
| **Durability** | Fragile (moving parts) | Fragile | Very durable (no moving parts) |
| **Portability** | Moderate | Very portable | Very portable (flash drives) |
| **Use case** | Desktop PCs, NAS | Software distribution, archiving | Laptops, OS drives |

### Primary vs secondary storage

| Primary storage | Secondary storage |
|----------------|------------------|
| Directly accessible by CPU | Not directly accessible — loaded into RAM first |
| Very fast | Slower |
| Volatile (RAM) or small/fixed (ROM, cache) | Non-volatile; persistent |
| Examples: RAM, ROM, cache | Examples: HDD, SSD, optical disc |

### Virtual memory

- When RAM is full, the OS moves the **least recently used** pages of memory to a **page file** on the HDD/SSD
- This gives the illusion of more RAM than physically exists
- **Trade-off:** much slower than real RAM because HDD/SSD access is slower
- Excessive use causes **thrashing** — the system spends most of its time swapping pages rather than executing instructions

### Cloud storage

**Advantages:**
- Accessible from anywhere with internet
- No local hardware to manage
- Automatic backups / redundancy
- Scales easily

**Disadvantages:**
- Requires internet connection
- Ongoing subscription cost
- Security/privacy concerns — data held by third party
- Latency compared to local storage

## Worked examples

### Example — Selecting appropriate storage

**Scenario:** A hospital needs to store patient scan images (each ~500 MB) for 20 years, accessed occasionally.

**Analysis:**
- High capacity needed → HDD or cloud
- Infrequent access → speed less critical
- Long-term → durability important
- Regulatory requirements → security/backup needed

**Suitable choice:** Cloud storage (for accessibility and redundancy) backed up to high-capacity HDD. Not optical — too slow/low capacity.

## Common mistakes

- ❌ **Mistake:** Saying ROM is "read-only" so it cannot be updated.  
  ✅ **Correction:** Modern ROM (EEPROM/Flash ROM) can be updated via a firmware update process, though it is not designed for frequent writes.

- ❌ **Mistake:** Confusing virtual memory with RAM.  
  ✅ **Correction:** Virtual memory is a section of **secondary storage** that *acts* as extra RAM — it is much slower than real RAM.

## Quick-check questions

1. What is the difference between volatile and non-volatile storage?
2. Give two advantages of SSD over HDD.
3. What is virtual memory and when does the OS use it?
4. Give one advantage and one disadvantage of cloud storage.
5. Which type of primary storage stores the BIOS/UEFI firmware?

<details>
<summary>Outline answers</summary>

1. Volatile: loses data when power is removed (e.g. RAM). Non-volatile: retains data without power (e.g. HDD, SSD).
2. Any two: faster; no moving parts (more durable); quieter; less power consumption.
3. Virtual memory is a section of HDD/SSD used as if it were RAM when RAM is full; the OS uses it when RAM is exhausted.
4. Advantage: accessible from anywhere / automatic backup. Disadvantage: requires internet / security/privacy concerns.
5. ROM.

</details>
